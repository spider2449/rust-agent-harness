# Task 092 — RAH v0.9 Scope and Authority Roadmap

Date: 2026-08-25

## Scope

Research the released v0.8 repository state and define one recommended v0.9
product/authority center. This task is documentation-only. It does not change
Rust code, Cargo manifests/lockfile/dependencies, public APIs, PermissionLevel,
Trusted Profile `profile_version`, accepted ADRs, certified Codex baseline, or
release/tag state.

## Baseline inspected

- v0.8 release evidence at `0b12d5448dcea89b158e4941e7b741b7539c8894` and
  post-release `master` `1bbeea43ff3bf93f09c25dc4c3f6d5521437d407`.
- Architecture/security, v0.8 scope/release, file-creation contract, Codex
  baseline policy, ADRs 0010--0013, repository mutation/create/observer and
  trusted-profile implementation, session store, and relevant v0.7/v0.8
  plans/live-gate documents.

## Decision

Recommend bounded multi-file edits over a small host-fixed set of existing,
clean HEAD-tracked UTF-8 files. The operation retains independently
preconditioned exact literal replacements, prepares every postimage before the
first mutation, commits in deterministic host-owned order under the shared
repository lease, and explicitly has no cross-file transaction, rollback,
retry, or replay claim.

The fallback is bounded repository directory creation, not generic write,
richer patch parsing, or Git history/ref authority.
