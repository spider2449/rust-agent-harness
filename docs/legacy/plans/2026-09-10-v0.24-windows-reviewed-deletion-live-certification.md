## Explicit nonclaims and stop boundary

This certification will not claim browser/UI automation, model-selected or
model-authorized deletion, provider/MCP/Process Plugin deletion, generic
filesystem or directory deletion, rename/move, Stage/Commit, rollback,
Trash/Recycle Bin recovery, retry/replay, delete-pending recovery, polling,
race-free TOCTOU, OS sandboxing, network isolation, or Linux/macOS live parity.
Windows success-path certification does not replace deterministic failure
coverage from Task 283 and ADR 0025.

Task 285 stops after independent review of this Windows live certification.
