## Deterministic guard and CI

`crates/rah-desktop/tauri_permission_test.js` now derives the runtime,
manifest, generated-file, default-capability and production `status.js`
invoke inventories. It requires structural parses, uniqueness, exact
runtime/manifest/generated/default set equality, the frontend subset, and the
specific repaired frontend invokes. It checks every generated file's normal
allow/deny IDs and command mappings. It preserves focused Host Confirm,
Host Cancel, rename and repository membership assertions, and rejects
wildcards and broad `fs` permission. Mismatch reports identify missing and
surplus names. It uses built-in Node modules only.

`.github/workflows/ci.yml` adds one step, `Check Desktop Tauri permissions`,
to run `node crates/rah-desktop/tauri_permission_test.js` in exact-head CI.
