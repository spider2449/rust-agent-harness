## Release content

v0.5 releases the narrow trusted host-composed `repo.patch` capability: one
exact literal conditional replacement in one bounded existing HEAD-tracked,
unstaged strict-UTF-8 worktree file. The private
`RepositoryWorktreeMutationPolicy` remains the real authority;
`PermissionLevel::Execute` remains only an outer gate. ADR 0012 is Accepted.
Worktree content, index, and history/ref authority remain separate.

The changelog and release gate record SHA-256 plus byte-length preconditions,
bounded request/file/postimage handling, BOM/CRLF preservation, repository/path/
link/reparse/hard-link protections, same-directory temporary replacement,
one-attempt/no-replay behavior, known-versus-uncertain outcome classification,
trusted-profile composition, bridge evidence, and the Windows baseline.

## Platform statement and limitations

Windows is the verified release baseline. No Unix live-validation claim is made.
Non-blocking limitations are intentional: no create/delete/move, binary edits,
multi-file transactions, staged/untracked target mutation, restore-worktree,
Git history/ref mutation, network Git, rollback guarantee, or complete TOCTOU
elimination. Uncertain outcomes are never automatically replayed.
