## Release theme and authority classification

Theme: **Explicit Inactive Repository Member Removal**.

Product claim: Desktop can explicitly remove an inactive admitted repository
member from the current process-local workspace through an opaque
`RepositoryMemberId`, currentness/lifecycle checks, and inactive/nonbusy proof.
For active A and inactive B, removal yields only A while preserving active A.

active-repository removal.

already-admitted descriptive membership. It is not a ToolRegistry Tool,
Codex dynamic Tool, MCP Tool, Process Plugin Tool, HostExplicit capability,
repository filesystem authority, or Git authority. HostExplicit remains
