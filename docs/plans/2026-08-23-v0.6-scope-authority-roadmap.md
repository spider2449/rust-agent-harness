# Task 057: RAH v0.6 scope and authority roadmap

Status: Completed research; no implementation authorized
Date: 2026-08-23

## Scope

Research the highest-value RAH v0.6 product capability after the fully verified v0.5.1 release baseline. This task is documentation only. It does not modify Rust code, Cargo manifests, dependencies, public APIs, trusted-profile schemas, live examples, repo.patch, or accepted ADRs.

## Method

1. Verify the release history, working tree, architecture guardrails, ADRs 0010–0012, v0.5 milestone evidence, current tool/profile/session source, and Generic Tool Bridge boundaries.
2. Reassess the coding-agent workflow from first principles rather than treating repo.patch as a reason to add another mutation.
3. Score repository inspection, patch evolution, creation, delete/rename, commit/history, persistence, network MCP, PluginManager, profile reload, cross-platform validation, and a fixed test runner against consistent product, authority, security, testability, portability, integration, and release criteria.
4. Classify every candidate as existing-authority reuse, ADR 0012 extension, new authority/ADR, or broad authority deferred.
5. Specify one focused v0.6 recommendation, validation and profile/bridge expectations, explicit deferrals, technical-debt disposition, and the next research task.

## Decision

Recommend a bounded repository-aware read-only workflow inspection toolkit: repo.status, repo.diff, repo.diff-staged, and repo.file-info. The tools are one cohesive reliability capability: they let agents form fresh repo.patch preconditions and verify resulting/staged repository state without adding mutation, history, network, persistence, or lifecycle authority.

The intended implementation reuses host-fixed HostExecutionPolicy, repository identity validation, PermissionLevel::Execute, trusted-profile composition, ToolRegistry, and Generic Tool Bridge. No new ADR is required if Task 058 confirms the contract remains strictly read-only and fixed-command. Task 058 must instead stop for an ADR if research finds a material authority or stable-boundary change.
