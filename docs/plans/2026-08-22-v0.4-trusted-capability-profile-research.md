# Task 027 plan: trusted capability profile research

## Scope

Research and document the smallest safe v0.4 trusted-host capability-profile
boundary. This task is documentation-only: it does not parse profiles, register
tools from profiles, change a public type, add a dependency, or revise an ADR.

## Method

1. Use the v0.3 security model, ADRs 0007 through 0010, and the Task 026
   roadmap as the implemented-authority baseline.
2. Classify possible profile sources and define a strict, host-owned profile
   schema distinct from model tool schemas.
3. Specify symbolic-resource resolution, fail-closed validation, effective
   profile inspection, redaction, platform identity limits, and immutable
   lifecycle semantics.
4. Define deterministic and narrowly scoped opt-in live validation that a
   later implementation task can use.

## Deliverables

- Add `docs/RAH_V0.4_TRUSTED_CAPABILITY_PROFILE_RESEARCH.md`.
- State whether the proposed static-profile increment is sufficiently bounded.
- Clearly label VERIFIED, IMPLEMENTED, PLANNED, and DEFERRED claims.
