# v0.5.x post-release documentation cleanup

Date: 2026-08-22

Task: 056

Status: Complete

## Confirmed release state

- v0.5.0 is a published feature release. Its immutable annotated tag peels to
  `b1f0fb4a903a59e0b5c23ca107d7508ebcbd8786`, and its GitHub Release remains
  published.
- v0.5.0 contains the complete v0.5 `repo.patch` milestone and passed Windows
  release validation, including the live `repo.patch` gate.
- v0.5.0's required Ubuntu CI did not complete because clippy reported the
  unused unconditional `std::fs::File` import. `File` is used only in the
  Windows native-identity path, so this was a lint-only portability defect, not
  a `repo.patch` authority, correctness, or runtime-semantics defect.
- The public v0.5.0 tag and GitHub Release were preserved unchanged. Recovery
  used a patch release rather than moving the historical tag.

## Recovery and v0.5.1 release

- Recovery commit `6aae5b1fb710cb9d84fc1bcc51bddb9d1be9e22e` (`fix: gate
  repository patch file import`) gates the `std::fs::File` import with
  `#[cfg(windows)]`.
- The recovery CI run `32573592369` completed successfully on Ubuntu, including
  formatting, workspace check, workspace tests, and clippy.
- v0.5.1 release preparation is commit
  `0ea648d84d6f48720c33e8b1bb07e1c24101c870`; its annotated tag peels to that
  same commit locally and on `origin`.
- The GitHub Release `RAH v0.5.1` is published, not draft, and not prerelease.
- The release-preparation CI run `32574019502` and `v0.5.1` tag CI run
  `32574129999` both completed successfully.
- The v0.5.1 Windows live `repo.patch` release gate passed using exactly
  `codex-cli 0.149.0`. No Unix live Codex validation claim is made.

## Final post-release status

v0.5.1 is the current released, fully required-CI verified v0.5.x patch
baseline. It is a portability-only recovery: it introduces no product feature,
authority, public API, dependency, profile, Codex, or ADR change relative to
v0.5.0 beyond the cfg-gated import. v0.5.0 remains the historical published
feature release with its immutable tag preserved and its known lint-only Ubuntu
CI defect recorded.

ADR 0012 remains Accepted; ADR 0010 remains index-only; ADR 0011 remains a
composition-only authority boundary; and `RepositoryWorktreeMutationPolicy`
remains private. No release recovery altered authority semantics.
