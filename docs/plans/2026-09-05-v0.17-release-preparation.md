## Release claims and limits

The release documents the provider-only Desktop overlay, inert static
selection, Connect/reconnect activation, shared composition, local stdio MCP,
Process Plugin, exact Tool-set/schema admission, host-selected permissions,
fresh registry merge, duplicate fail-closed admission, provider lifecycle
ownership/cleanup, sanitized external descriptors, Configured/Effective/
Advertised/Current separation, and conservative external-effect handling.

Task 207 remains **INCONCLUSIVE / externally blocked for the model-selected
external Tool execution sub-gate**. The release does not claim Task 207 PASS,
live-certified external MCP or Process Plugin execution, Windows model-driven
external execution, real external ToolStarted/ToolFinished repository refresh,
or Linux external-provider live certification. The limitation was accepted by
Task 207C and Task 208.

The certified Codex baseline remains `codex-cli 0.149.0` with SHA-256
`14b7e6b2356e82d1d9275579eaa588757b4e0a501b65dcc19fccdf77bd83dc00`; the
current live-gate model is `gpt-5.6-terra`. Codex 0.153.4 is research-only
compatibility evidence and is not certified.
