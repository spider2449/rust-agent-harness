## Release commands

```powershell
cargo fmt --check
cargo check --workspace
cargo test --workspace
cargo clippy --workspace --all-targets --all-features -- -D warnings
git diff --check
cargo metadata --no-deps --format-version 1
```

## Explicit deferrals

No profile discovery, reload, editing, mutation, generic provider/subprocess
schema, network MCP, PluginManager, installation/download, automatic restart,
hot reload, generic shell/process authority, destructive worktree authority,
Git commit/ref/history/network/credential authority, model-facing profile API,
OS sandboxing, network isolation, or rollback guarantee is added by this task.

## Post-commit checks

Confirm a clean tree, inspect the release commit/stat, then rerun the release
commands against that clean commit. Do not tag, publish, push, merge, rebase, or
reset as part of release preparation.
