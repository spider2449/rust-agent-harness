# Task 260 — RAH v0.22 Deterministic HostExplicit Multi-File Backend

## Scope

Implement the backend-only HostExplicit route for the existing
`repo.edit-files` capability under ADR 0023. Reuse the Task 259
`RepositoryMultiFileEditPreparer` for all preparation and revalidation, and
reuse the existing HostExplicit coordinator, D2, authorized dispatch, result
handling, refresh, and authorization invalidation boundaries.

Frontend/UI work, live Windows certification, generic invocation, structural
Tool eligibility, persistence, rollback, Stage/Commit automation, and Task
261 are out of scope.

## Implementation checklist

- [x] Add only `repo.edit-files` to the exact HostExplicit backend allowlist.
- [x] Add closed camelCase multi-file Prepare DTOs and a ticket-only response.
- [x] Compose and retain the shared multi-file preparer and opaque preparation.
- [x] Preserve coordinator reservation, five-minute single-use tickets, D2,

- [x] Map shared preparation failures distinctly and classify the existing six

- [x] Invalidate repository-bound reviewed authorization after Started and

- [x] Add/complete deterministic focused tests for route, preparation,
      currentness, result mapping, privacy, and invalidation.
