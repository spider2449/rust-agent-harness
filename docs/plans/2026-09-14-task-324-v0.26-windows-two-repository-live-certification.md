## Scope and method

The required harness is the ignored Windows-only test
`task_324_windows_two_repository_live_certification` in the existing Desktop
test module. It is gated by `RAH_RUN_V026_MULTI_REPO_LIVE=1` and uses the
existing certified Codex live-gate environment. It creates two fresh sibling
repositories beneath one fresh temporary root, uses native Git and the real
Desktop admission, activation, connection, runtime/tool bridge, Stage, and
Unstage paths, and removes only that certification root after all handles are
closed.

## Limitations and nonclaims

The zero-provider live run does not newly certify provider-specific repository
interaction; host-owned selection and deterministic Task 323 evidence remain
authoritative for that boundary. A live stale HostExplicit ticket is optional
and will be reported as deterministic-only if the current lifecycle prevents
safe preparation/switching without a production seam. Nested-boundary live
parity, rollback, race-free TOCTOU, network isolation, OS sandboxing, and
full executable restart semantics are not claimed unless directly measured.
