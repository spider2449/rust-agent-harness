## Finding

The audit found a material ordinary ADR 0018 gap on Windows. The current
`destination_git_absent` proof checks Git HEAD and index paths by exact byte
spelling. Windows filesystem destination identity is case-insensitive, so a
tracked `README.md` that is absent from the worktree can evade the Git check
when the requested destination is `readme.md`. A no-replace native rename can
then create a case-equivalent destination alias, violating the ordinary
destination absence and Windows alias/case protections.

Existing exact-case tracked-destination and case-only source/destination tests
pass, but they do not close this tracked-but-missing case-equivalent collision.
This is an ordinary mutation-authority defect and cannot be hidden behind the
reviewed HostExplicit route.

## Required correction

Create and execute a separate focused correction task for ordinary
`repo.rename-file` destination collision proof. The correction must compare
all relevant Git HEAD and index paths under the platform's filesystem path
equivalence rules, preserve the ADR 0018 one-native-attempt and strict proof
contract, and add deterministic coverage for a tracked-but-missing
case-equivalent destination. Release preparation remains deferred until that
correction is implemented, audited, and validated.
