# Task 261 — RAH v0.22 Desktop Typed Multi-File Review Workflow

## Scope

Implement the Desktop/frontend presentation and input workflow for the existing
Task 260 `repo.edit-files` HostExplicit backend route. Preserve the backend
authority boundary, exact eight-tool HostExplicit eligibility, Task 259
preparation/revalidation, and ADR 0023 semantics. Do not start Task 262.

## Implementation checklist

- [ ] Add a backend-derived `repo.edit-files` authoring form with bounded typed
      targets and literal replacements only.
- [ ] Send only the closed human Prepare DTO to
      `host_prepare_repo_edit_files`; render the returned review as immutable
      backend-derived content.
- [ ] Send only `{ ticketId }` to Confirm and Cancel; consume the ticket from
      the UI after either terminal action or submission failure.
- [ ] Render the complete multi-file review, non-atomic/no-retry warnings,
      conservative six-class results, and stale/review-too-large failures.
- [ ] Keep HostExplicit activity redacted and separate from transcript and
      durable browser storage; use safe text rendering for all source content.
- [ ] Extend deterministic frontend authority/DTO/review/confirm/cancel,
      result, privacy, and injection-safety assertions.
