## Limitations and blocker search

It leaves the file untracked; it cannot stage, commit, edit ignored/staged/tracked targets, write arbitrary paths, or switch repositories. HostExplicit remains exactly 11. The older v0.32 `repo.list` remains bounded direct-child structural listing of tracked inventory, without file content reads, recursive browse, or arbitrary untracked/ignored enumeration.
