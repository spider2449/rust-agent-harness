## Release decisions and preserved nonclaims

`repo.search` remains `ReadOnly` / `RepositoryObservation` / `Execute` /
repository-bound. HostExplicit remains exactly the existing 11-name set;
`repo.search` and `repo.create-directory` are not eligible. No mutation,
network, persistence, generic Git, generic shell/process, or new permission
authority was introduced.

The unavailable `codex-cli 0.149.0` is an explicit release nonclaim, not a
blocker. Task 369 certified production behavior and actual Generic Tool Bridge
dispatch; it did not certify real model-selected inference under 0.149.0, and
ambient 0.155.1 was not substituted.

Windows symlink live behavior is also an explicit nonclaim, not a blocker.
Deterministic coverage exists and junction/reparse live behavior passed; the
gate does not claim a Windows symlink live pass.

Task 368 proved the known parallel-test contention family against the clean
pre-Task-367 baseline. It is not a `repo.search` regression. Deterministic
serial workspace validation is the local release gate; default parallel test
status must not be reported as passing unless actually run and passing.
